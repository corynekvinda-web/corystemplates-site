Hi, I’m Cory.

I kept buying planner PDFs that were almost right — a page I loved next to ten I’d never use. So I built the tools to make my own, and it turns out other people wanted the same thing.

Everything here follows C.O.R.Y.S.T. — Create Original, Reusable Yours, Subscription-free Templates. I build the planners I use myself, from Fort Dodge, Iowa.
